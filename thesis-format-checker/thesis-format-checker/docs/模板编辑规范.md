# 论文格式检测模板编辑规范（用户版）

## 1. 这份规范解决什么问题

本系统不把某一所学校的字号、页边距或标题编号写死在程序里，而是把您提供的
“规范模板”当作标准，提取模板中的结构和格式，再与待检测论文逐项比较。因此，模板
不仅要看起来正确，还要让 Word 和程序能够识别“这是什么对象、属于哪个层级、应当
怎样排版”。

本规范面向高校、学院、教务管理人员和论文模板维护人员。按本规范制作模板后，即使
不同学校采用不同的标题编号、字体、页眉或组成顺序，系统也可以根据各自模板建立基准。

### 1.1 最重要的四条原则

1. **模板即标准**：模板中出现且能被识别的要求，系统才有可靠的比较依据。
2. **使用 Word 原生对象**：标题用样式和多级列表，目录用自动目录，页码用域，公式
   优先用 Word 公式，图表题注使用题注段落。
3. **同类对象保持一致**：同级标题、正文、题注、公式、参考文献不要在模板中出现
   互相矛盾的格式。
4. **示例真实、完整、可读取**：示例文字不要做成图片，也不要只放在文本框、艺术字
   或 OLE 对象中。

### 1.2 模板问题会怎样影响检测

| 模板情况 | 检测结果 |
| --- | --- |
| 有可识别且一致的样例 | 可给出“符合/不符合”以及应该值、实际值 |
| 没有对应样例 | 该项可能不适用，或在报告中记为无法判定 |
| 同类样例互相矛盾 | 按同层级、同位置和可确认基准比较；证据不足时只写报告 |
| 对象位于图片、文本框或不可解析 OLE 内 | 对象内部格式通常无法可靠检测 |
| 模板本身有批注、修订或占位提示 | 可能污染基准或被识别为残留内容 |

“无法判定”只保留在 JSON 报告中，不会作为批注写入论文。

## 2. 模板交付要求

### 2.1 文件要求

- 提供一个完整的 `.docx` 文件；不要用 PDF、截图、扫描件或 `.docm`。
- 交付前在 Word 中接受所有修订，并删除模板原有批注。
- 不设置打开密码、编辑密码、信息权限管理或只读保护。
- 删除无关示例、隐藏对象、宏、外部链接和会弹出提示的自动化内容。
- 建议命名为 `学校-培养层次-论文模板-v版本号.docx`。
- 模板更新后修改版本号，并重新做模板体检和样例论文回归验证。

### 2.2 模板应包含的组成部分

没有要求的部分可以不放；要求存在的部分，必须提供可识别示例。

| 对象 | 建议示例数量 | 推荐写法 |
| --- | ---: | --- |
| 封面、题名页 | 各 1 页 | 文字字段用普通文字或表格单元格，不要整页做成图片 |
| 原创性/独创性声明、授权声明 | 各 1 份 | 标题和正文为可编辑文字，签名和日期有明确填写区 |
| 中英文摘要、关键词 | 各 1 份 | 标题、正文、关键词分别使用稳定样式 |
| 自动目录 | 1 份 | 使用“引用 → 目录 → 自动目录”插入 TOC 域 |
| 每一级标题 | 每级至少 2 个 | 使用标题样式、大纲级别和多级列表 |
| 正文段落 | 至少 3 段 | 使用正文样式，覆盖常用段落格式 |
| 图片+图题、表格+表题 | 各至少 2 组 | 题注为独立段落，编号形式保持一致 |
| 独立公式、行内公式 | 各至少 2 个（如适用） | 使用 Word 公式；独立公式示范编号和布局 |
| 脚注/尾注、交叉引用 | 各至少 2 处（如要求） | 使用 Word 原生功能 |
| 参考文献 | 至少 3 条 | 覆盖实际采用的中英文和文献类型 |
| 附录、致谢、成果目录 | 各至少 1 份 | 标题和正文使用对应样式 |

## 3. 样式、标题和编号

### 3.1 用样式表达层级

一级、二级、三级标题应分别使用稳定的标题样式，并设置正确的大纲级别。样式名称不必
固定为“标题 1/标题 2/标题 3”；学校可以使用“章标题”“节标题”等自定义名称，
但同一层级必须统一。

正文、摘要正文、关键词、图题、表题、目录条目、参考文献和附录正文也应尽量使用
各自样式。直接选中文字逐段修改字体，只适合封面个别字段，不适合定义整类对象。

### 3.2 标题编号可以不同，但必须可解析

系统支持模板定义的不同编号体系，例如 `第一章/第一节`、`1/1.1/1.1.1`、
`第1章/1.1` 等。请通过“开始 → 多级列表 → 定义新的多级列表”把每一级编号链接到
对应标题样式，不要在标题文字前手工输入编号。

纯手工编号、没有样式、没有大纲级别、也没有目录证据的特殊标题，系统无法安全推断
层级。历史模板确实无法改造时，可在映射文件中显式配置 `heading_styles`。

### 3.3 同类样例不要冲突

同一级标题至少放两个真实示例，并确保字体、字号、加粗、对齐、缩进、段前段后、行距、
编号分隔符和分页属性一致。正文、题注、目录和参考文献同理。系统不会简单认定第一个
样例或多数样例必然正确。

## 4. 各部分编辑要求

### 4.1 封面和题名页

- 推荐使用表格稳定排列字段，一行或一个单元格表达一个明确字段。
- 论文题目、姓名、学号、学院、专业、班级、指导教师、日期等必须是可编辑文字。
- 校徽和校名图片可放在表格单元格中，但不要把整个封面合并成一张图片。
- 图片尺寸、表格宽度、单元格宽度、行高和页面位置都可能成为模板基准。
- Word 中查看单元格宽度：选中单元格，打开“表格工具 → 布局 → 单元格大小”，或
  右键“表格属性 → 单元格 → 指定宽度”。程序报告的磅值可按 `1 磅≈0.3528 毫米`
  换算。若开启了自动调整、合并单元格或表格总宽度受页面限制，显示值可能是实际布局宽度。
- 不要用空格或连续回车模拟左右位置；使用表格、段落对齐、缩进和制表位。

### 4.2 声明和授权页

- 原创性/独创性声明和使用授权声明应分别具有可识别标题和正文。
- 导师签名、作者签名、日期属于哪一份声明，要在该声明正文中设置明确填写区。
- 占位形式应稳定，例如“导师签名：________”“日期：____年__月__日”。
- 不要把声明扫描成图片。不同声明不要共用一个含混标题。

### 4.3 摘要和关键词

- 中文摘要、英文摘要的标题、正文、关键词分别使用稳定样式。
- “关键词/Key words”等标签与内容建议位于同一段，使用明确分隔符。
- 模板应示范允许的关键词数量和分隔符；不要只放“关键词：”而没有示例内容。
- 模板中的缩略语示例应采用学校要求的首次出现写法。

### 4.4 目录

- 必须使用 Word 自动目录（TOC 域），不要手工输入目录文字和页码。
- 目录显示层级由 TOC 域开关控制，并与模板实际标题层级一致。
- 页码位置使用右对齐制表位和前导符，不用空格推到右侧。
- 交付前按 `Ctrl+A` 后按 `F9` 更新全部域，并检查目录文字和页码。
- 不要在 TOC 域边界前后保留空的伪目录段落。

### 4.5 正文和分页

- 正文样例应覆盖学校实际要求的中文、西文字体、字号、对齐、首行缩进、行距、段前段后。
- 章标题另起页时，使用“段前分页”或规范分节，不要插入大量空行。
- 标题需与后续内容同页时，在标题样式中设置“与下段同页”，避免人工反复回车。
- 需要横向页、不同页边距或其他特殊页面时单独分节，并在模板中放置真实示例。

### 4.6 页眉、页脚和页码

- 先明确哪些页面显示页眉、页脚和页码：封面、声明、前置部分、正文、附录可分别设置。
- 使用分节符表达区域差异，并正确设置“链接到前一节”。不要用空段落模拟分节。
- 需要“首页不同”或“奇偶页不同”时，在模板中实际启用并提供可见页面示例。
- 页码必须使用 PAGE 域；罗马数字、阿拉伯数字、起始值和重新编号方式均在节中设置。
- 页眉/页脚距边界、字体、字号、对齐、边框和内容均应按最终要求设置。
- 如果模板未启用偶数页页眉，系统会按 Word 的继承关系使用普通页基准，不要额外建立
  一个没有实际页面使用的空变体。

Word 不允许把普通批注直接插入页眉页脚。系统会把页眉问题定位到受影响页的正文顶部，
把页脚问题定位到该页正文底部，使用不改变排版的零长度锚点；没有可靠页面边界时只进报告。

### 4.7 图、表和题注

- 图片和表格使用 Word 正文中的原生对象，不要仅放在文本框里。
- 图题通常位于图下，表题通常位于表上；以学校模板为准。
- 题注为独立段落，统一字体、字号、对齐、间距和编号方式。
- 编号尽量使用 Word 题注/SEQ 域并包含章节号（如学校要求），不要手工输入一部分编号。
- 三线表、表头、表身、合计行、边框、底纹和跨页重复标题行应在模板中真实示范。
- 附录中的图表若采用独立编号，模板中要给出真实附录样例。

### 4.8 公式

- 可编辑公式使用 Word OMML 公式；MathType/OLE 或公式图片的内部字体不一定可读取。
- 行内公式直接放在正文行内；系统只比较公式本身可读取的字体和字号，不拿正文段落布局
  当作公式布局。
- 独立公式使用独立段落，明确示范居中、编号右对齐、编号格式、段前段后和行距。
- 同类公式至少放两个完整样例。不要用半句正文代替公式名称或用空格推公式编号。

### 4.9 引用、脚注和参考文献

- 图、表、章节和公式引用使用 Word 交叉引用或可识别域，并在交付前更新。
- 脚注、尾注使用 Word 原生功能，示范编号方式、字体、字号、缩进、行距和分隔线。
- 参考文献应提供真实但可公开的完整样例，覆盖实际采用的文献类型和中英文格式。
- 同一类型、同一语言的著录字段与标点应一致；不要把说明文字混入参考文献条目。

## 5. 不推荐或无法可靠读取的写法

| 写法 | 影响 | 建议 |
| --- | --- | --- |
| 纯手工标题编号 | 难以可靠识别层级和连续性 | 使用多级列表并链接标题样式 |
| 手工目录、空格推页码 | 无法可靠核对层级和页码 | 使用 TOC 域和右对齐制表位 |
| 文本框中的正文/题注 | 不属于普通正文段落 | 改为正文段落；文本框仅作装饰 |
| 整页截图或扫描封面 | 无法读取字段和文字格式 | 保留文字字段，只把校徽等作为图片 |
| MathType/OLE/公式图片 | 内部字符格式读取受限 | 优先使用 Word 公式，或接受只检查外围布局 |
| 大量空行、空格定位 | 分页或位置随内容变化 | 使用分页属性、表格、缩进、制表位 |
| 未更新的域 | 目录/页码/交叉引用可能过期 | 交付前 `Ctrl+A`、`F9` 并保存 |
| 隐藏示例或白色文字 | 可能被识别为正文残留 | 删除而不是隐藏 |

## 6. 不同学校模板如何接入

系统不会假定固定的学校名称、章节文字或编号体系。只要模板使用可解析的 Word 结构，
标题、正文、目录、页眉页脚、图表和公式都可按当前模板建立基准。以下情况可能需要
附加映射配置：

- 模板使用非标准样式名且大纲级别不完整；
- 论文和模板的正文范围无法仅凭标题或样式识别；
- 论文分节与模板分节不一一对应；
- 某一页眉节需要显式对应模板中的另一节。

映射文件可参考 `examples/mapping.example.yaml`。配置是补充证据，不应替代模板规范化。

## 7. 交付前操作和体检

在 Word 中完成：

1. 接受全部修订并删除批注。
2. `Ctrl+A`、`F9` 更新目录、页码、题注和交叉引用域。
3. 检查每级标题样式、大纲级别和多级列表链接。
4. 检查每一节的页面设置、首页不同、奇偶页不同、链接到前一节和页码起始值。
5. 显示格式标记，删除多余空段、手工分页替代物、隐藏文字和无关示例。
6. 保存、关闭并重新打开，确认目录、分页和图片没有变化。

然后在项目根目录运行：

```powershell
Set-Location -LiteralPath 'D:\Lenovo\Documents\南理\thesis-format-checker'
.\.venv\Scripts\python.exe tools\check_template.py 'D:\模板\规范模板.docx'
```

体检结果中的“必须补齐”应全部处理；“建议”应逐项确认是否为学校有意设计。模板体检只检查
可机器识别性，不能替代学校对内容和视觉效果的人工审定。

## 8. 最终验收清单

- [ ] 文件为可正常打开的 `.docx`，无密码、宏、修订和批注。
- [ ] 所有必需组成部分均有可编辑文字和真实示例。
- [ ] 各级标题使用样式、大纲级别和自动多级编号。
- [ ] 自动目录已经更新，目录页码使用右对齐制表位。
- [ ] 正文、摘要、题注、参考文献等同类样例格式一致。
- [ ] 页眉、页脚、页码及首页/奇偶页设置有实际页面样例。
- [ ] 图、表、公式、脚注、引用和附录使用 Word 原生对象。
- [ ] 没有用大量空格、空行、文本框或截图代替结构化排版。
- [ ] 模板体检已通过，并用至少一篇样例论文完成端到端检测和人工复核。
